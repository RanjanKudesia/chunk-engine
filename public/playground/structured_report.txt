Risk 1: Upstream API rate limits
Third-party geocoding API introduced new rate limits in February.
Current usage is at 72% of the new limit. Caching implementation is underway.
Expected completion: 2026-04-15.

Risk 2: Database version end of life

Migration to PostgreSQL 16 is scheduled for Q2.
Test environment migration completed successfully.

Risk 3: Single point of failure in batch processing
Nightly batch job runs on a single worker with no failover.
Redesign to distributed job queue is in progress.
Expected completion: 2026-05-30.
